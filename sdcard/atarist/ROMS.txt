# ATARIST (Atari ST/STE/MegaSTE) ROM notes.
#
# Zero-config default: EmuTOS 1.4 UK (GPL) is staged at
# /roms/ATARIST/etos512uk.img and boots straight to GEM. No action needed.
#
# Genuine TOS pool (proprietary, NEVER in git): unzip TOS images into
# /roms/ATARIST/ on the SD card:
#   tos106uk.img - TOS 1.06 UK (STE)
#   tos162uk.img - TOS 1.62 UK (STE, latest STE TOS)
#   tos206uk.img - TOS 2.06 UK (MegaSTE)
# Floppies live on the SD card under /systems/ATARIST/disks (.ST/.MSA/.STX;
# .STX is the Pasti format for copy-protected originals, served through
# the FDC emulation including track-level reads).
# Screenshots land on SD:/screenshots/atarist (shotNN.bmp, folder created
# on demand). Save states land in /systems/ATARIST/snapshots (*.vsf).
